# 🐢 Turtle Graphics – Python Drawing Project

Este projeto utiliza o módulo **turtle** do Python para criar desenhos geométricos, padrões coloridos, random walks e spirographs.  
É uma excelente forma de praticar lógica, funções, ciclos e manipulação gráfica em Python.

---

## 🎨 Funcionalidades

O script inclui várias funções que desenham diferentes tipos de figuras:

### ✔️ **Cores Aleatórias (RGB)**
- Gera cores aleatórias usando `colormode(255)`
- Cada desenho pode ter uma cor diferente

### ✔️ **Quadrado**
- Desenha um quadrado com 4 movimentos e rotações de 90°

### ✔️ **Linha Tracejada**
- Linha composta por segmentos alternados (desenha / não desenha)

### ✔️ **Figuras Geométricas**
Desenha automaticamente:
- Triângulo  
- Quadrado  
- Pentágono  
- Hexágono  
- Heptágono  
- Octógono  
- Nonágono  
- Decágono  

Cada figura com uma cor aleatória.

### ✔️ **Random Walk**
- Movimentos aleatórios em 4 direções (N, S, E, W)
- Cores aleatórias
- Espessura configurável
- Velocidade rápida

### ✔️ **Spirograph**
- Desenha círculos rotacionados com um gap definido
- Cores aleatórias
- Efeito visual hipnotizante
